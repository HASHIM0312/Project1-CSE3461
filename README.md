## Feature 3: Encrypted Messaging & Latency Benchmarks

### High-Level AES Encryption Logic
- **Cipher:** AES-256 in EAX mode with PKCS7 padding (`pycryptodome`).
- **Keys & IV:** 32-byte key and 16-byte IV generated by `key_generator.py` and stored in `keyIV.txt`.
- **Packaging:** Encrypted bytes are Base64-encoded for safe text transmission over TCP sockets.
- **Protocol Tags:** Messages are prefixed with `ENC:` (encrypted) or `RAW:` (unencrypted), framed by a 4-byte length header.

---

### How to Run

1. **Generate Key and IV:**
   ```bash
   cd feature3
   python3 key_generator.py
   ```

2. **Start the Server:**
   ```bash
   python3 server.py
   ```

3. **Start the Client:**
   ```bash
   python3 client.py [server_ip]   # defaults to 127.0.0.1 if omitted
   ```

---

### Sending Messages (Encrypted or Plaintext)
1. Enter your username when prompted.
2. Type your message and hit Enter.
3. When prompted `Encrypt message? (y/n):`:
   - Enter `y` to encrypt with AES (`ENC:` tag).
   - Enter `n` to send as plaintext (`RAW:` tag).
4. Enter `exit` to disconnect.

---

### Benchmarking & Latency Measurements
Enter either command in the client message prompt:

1. **`benchmark` (Client-Side Encryption Overhead)**
   - Measures local CPU processing time over 10,000 iterations across multiple message sizes (1B to 4KB).
   - **Client Terminal Output:** Displays average execution time (ms) without encryption, with encryption, and additional overhead.

2. **`benchmark_rtt` (End-to-End Round-Trip Time)**
   - Connects to the server, transmits payloads over TCP, and times until the server replies with `ACK` over 1,000 iterations per size.
   - **Client Terminal Output:** Displays message size, average RTT (ms), median RTT (ms), and network encryption overhead.
